D2Game.dll has some offsets changed to allow your merc to equip more than 1 Ring at the same time. May be unstable use at your own risk!
The .dll is not mandatory to play the mod but without it your merc will only be able to equip 1 ring at the same time.

-Replace D2Game.dll in the Diablo 2 root folder (same folder where Game.exe lives)
